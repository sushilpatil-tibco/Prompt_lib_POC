# TIBCO BW6 Prompt Library

Welcome to the **TIBCO BW6 Prompt Library**.

This repository contains curated prompt templates and implementation examples for developing applications in **TIBCO ActiveMatrix BusinessWorks 6 (BW6)**.

The goal of this library is to help:
- Integration developers
- Middleware engineers
- API developers
- Enterprise architects
- Support teams

quickly generate BW6 implementation patterns, starter templates, troubleshooting flows, and reusable development prompts.

---

# Included Categories

The prompt library currently includes examples for:

- REST Services
- SOAP Services
- JMS Messaging
- JDBC Database Processing
- File Processing
- Subprocess Design
- Module Properties
- Shared Resources
- Logging & Validation
- Retail Integration Examples
