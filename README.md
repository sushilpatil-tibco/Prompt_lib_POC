# TIBCO BW6 Prompt Library

This repository contains a DevHub / TechDocs-ready prompt library for TIBCO BusinessWorks 6 examples.

## Files included

- `catalog-info.yaml` - Marketplace catalog metadata
- `mkdocs.yaml` - Documentation navigation
- `docs/` - Prompt library pages

## First-time GitHub upload steps

1. Go to GitHub.
2. Create a new repository named `tibco-bw6-prompt-library`.
3. Upload all files from this folder.
4. Commit the files to the `main` branch.
5. Register `catalog-info.yaml` in DevHub marketplace if your platform requires manual catalog registration.

## Editing prompts later

Edit the `.md` files under the `docs` folder. After editing, commit the changes.
